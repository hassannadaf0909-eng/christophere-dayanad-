CHRISTOPHERE DAYANAD PREMIUM BIRTHDAY WEBSITE

1. Open birthday.html in Chrome/Edge.
2. Optional music:
   - Put your legally obtained copy of "Raga of Revenge" in this same folder.
   - Rename it to: raga-of-revenge.mp3
   - Click "Music: OFF" in the top-right.
3. The site works offline except for the Google Fonts import; if offline,
   the browser will fall back to standard fonts.
4. birthday_preview.png is a visual preview/mockup of the design.

The site includes:
- One-by-one NEXT navigation
- Back button
- Animated cake
- Falling hearts
- Stars
- Fireworks on the final screen
- MS Dhoni No. 7 themed chapter
- Vijay Thalapathy themed chapter
- Grandma chapter
- Final "Best Friend Forever ❤️" screen
